#  Netflix Clone

A responsive Netflix Clone web application that replicates the UI/UX of Netflix. This project is built for practicing front-end development skills and creating a modern streaming platform interface.

##  Features

- Responsive design (mobile, tablet, desktop)
- Hero banner section
- Movie/TV show categories
- Horizontal scrolling sections
- Hover effects and smooth UI interactions

##  Technologies Used

- HTML5
- CSS3 (Flexbox & Grid)
- JavaScript (Basic interactivity)
